# Сайт-визитка: Детейлинг & Дооснащение автомобилей (Частный мастер)

Современный статический сайт-визитка, разработанный по принципам дизайн-методологии **unslop**:
- Строгая 4px сетка, сдержанная графитовая гамма, чистая типографика.
- Без визуального мусора: никаких светящихся фиолетовых градиентов, эмодзи в заголовках и шаблонных AI-штампов.
- Калькулятор стоимости с возможностью отправить выбранный список мастеру в один клик.
- Интеграция мессенджеров: Telegram, ВКонтакте, МАКС и прямой телефон.
- Официальные бейджи отзывов (Яндекс Карты, 2ГИС).

## Как настроить под свои данные

Откройте `index.html` в текстовом редакторе и замените шаблонные контакты на реальные:
1. **Telegram:** замените `your_telegram` на ваш username (например, `https://t.me/my_detailing`).
2. **ВКонтакте:** замените `your_vk` и `YOUR_VK_ID` на адрес вашей группы или страницы.
3. **Мессенджер МАКС:** замените `https://max.im/your_max_link` на вашу персональную ссылку.
4. **Телефон:** замените `+7 (999) 000-00-00` на реальный номер.
5. **Адрес:** укажите ваш фактический город и адрес бокса в блоке контактов.

## Деплой на GitHub Pages

Сайт полностью статичен (HTML + Tailwind CDN + Lucide Icons) и работает без сборщиков:
- Включается в настройках репозитория: **Settings -> Pages -> Branch: main -> / (root) -> Save**.
